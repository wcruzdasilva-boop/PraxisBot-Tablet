# PraxisBot Tablet

Aplicativo companheiro (PWA) do **PraxisBot** para registro em sala de aula (chamada, aulas e filas) sincronizado com o computador com criptografia ponta-a-ponta (E2EE).

- **Abrir no tablet:** https://wcruzdasilva-boop.github.io/PraxisBot-Tablet/
- **Instalar como app no Android (Chrome):** abra o link acima → menu `⋮` → **Adicionar à tela inicial / Instalar aplicativo**.
